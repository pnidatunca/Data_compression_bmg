## Proje Açıklaması
Bu proje, verilen bir metni **RLE (Run-Length Encoding)** algoritması ile sıkıştıran ve daha sonra tekrar eski haline dönüştürebilen (decode) bir Python programını içermektedir.

RLE, art arda tekrar eden karakterleri sayarak saklayan basit bir kayıpsız veri sıkıştırma yöntemidir.  
Örneğin:

- **Girdi:** `AAAAABBBCCDAA`  
- **Sıkıştırılmış:** `5A3B2C1D2A`  
- **Geri açılmış:** `AAAAABBBCCDAA`  

Ayrıca program sıkıştırma oranını (%) hesaplamaktadır.
